suppose you write:

name = "Ali"
marks = 90

These values exist while the program is running.

But after the program ends, those variables disappear from memory.

What if you want the marks to remain stored?

You need a file.

For example:

students.txt



Think of it this way:

Variable
   │
   │ temporary
   ↓
Computer Memory (RAM)
   │
   │ program closes
   ↓
Data disappears

But:

Python Program
      │
      ↓
    File
students.txt
      │
      ↓
Data remains stored
